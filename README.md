# Hmp.Devops.Tools

A collection of Azure DevOps automation tools and utilities used by HMP.
These tools are built as general as we can. So feel free to fork for your own use.

## Projects

### Hmp.Devops.Tools.EnvironmentRemover

An Azure Function that handles Azure DevOps webhooks for pull request closing events. See [detailed documentation](docs/tools/EnvironmentRemover.md) for more information.
